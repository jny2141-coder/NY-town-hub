# NY Town

나만의 생활 관리용 **3D 마을 웹앱** (Claude 아티팩트로 만들 예정).

## 큰 틀
- 아이소메트릭 3D 마을을 캐릭터로 걸어다니고, **건물 하나가 생활 영역 하나**를 맡는다.
- 건물에 들어가면 그 영역을 담당하는 **Claude 비서**가 있고, Google Calendar · Gmail · Google Drive · Notion과 연결된다.
- 건설 모드로 땅·건물·자연·장식을 직접 꾸미고, 마을과 기록은 아티팩트 DB에 저장한다.

## 목적 (생활 영역 = 건물)
| 영역 | 하는 일 |
|---|---|
| 집 | 오늘 브리핑, 일정, 할 일 |
| 학교 | 경희대 수업·학점·강의 자료·학교 메일 |
| 도서관 | KICPA 수험 공부 |
| 일터 | 아르바이트 업무 메일·근무 일정 |
| 그 밖 | 영어 회화, 주식, 블로그, 취미·전시, 관심 분야 탐구, 쇼핑, 요리 레시피 |
